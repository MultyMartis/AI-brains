# Factory Engineer Workflow

## Steps

1. Load:

- project-registry
- lifecycle-log
- agent-registry
- planning-layer.md
- v2-ai-brains-roadmap.md
- terminology-map.md
- engineer-protocol.md
- agent-standard.md

2. Orient:

### A. Standards compliance

- confirm task fits Main Brain rules and engineer-protocol
- map internal terms to standard roles via terminology-map when communicating externally

### B. System context

- identify current agents, gaps, and roadmap priorities
- note dependencies called out in agent cards and registries

### C. Design or evolution target

- define the agent, subsystem, or change in scope
- list target files and registry updates that would be required (proposal only unless user approves execution)

### D. Risk and approval

- surface risks, unknowns, and required user approval for structural changes
- do not auto-commit; output is a design package and recommended sequence

3. Output:

**FACTORY ENGINEER DELIVERABLE**

Sections:

- Summary
- Proposed design (or delta)
- Target files and registry rows
- Risks
- Recommended next steps
- Open questions (SAFE UNKNOWN where needed)
