# Agent Builder Workflow

## Steps

1. Receive approved agent request
2. Read agent-standard.md
3. Define agent identity:
   - agent_id
   - agent_name
   - standard_name
   - agent_type
   - owner_system
   - status

4. Create required files:
   - README.md
   - agent-card.md
   - workflow.md
   - changelog.md

5. Prepare registry update
6. Prepare lifecycle update
7. Request FlyCheck validation

## Output

AGENT BUILDER REPORT

- created structure
- generated files
- registry changes needed
- lifecycle changes needed
- risks
- next actions
