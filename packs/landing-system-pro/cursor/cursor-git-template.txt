GIT — local commands (Landing System PRO client repos)
================================================================================
Remotes are **optional**. Skip `pull` / `push` if you work **local-only**.

# Start from clean main
git checkout main
git status
# git pull origin main          # only if remote exists

# Branch per unit of work
git checkout -b task/SHORT_SLUG
# OR for a wide single pass:
# git checkout -b pass/SHORT_SLUG

# …edit src/, run build…

git status
git add PATH_OR_DOT
git commit -m "feat(block): imperative description"

# Optional tag after stable layout
git tag -a v-handoff-1.0 -m "Stable layout — PROJECT_NAME"

# Optional push
# git push -u origin task/SHORT_SLUG
